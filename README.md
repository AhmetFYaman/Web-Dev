# Web development coursework

My work for IFSC 1310, including HTML pages, CSS exercises, and a site about space telescopes. This repo shows the smaller steps I took while learning to build websites.

[View the coursework site](https://ahmetfyaman.github.io/Web-Dev/)

## Main project

[Space Telescopes](Telescopes%20Web-Dev) is a static website about Hubble, Webb, and Chandra. It includes telescope information, an FAQ, and a contact page. I worked with page layouts, navigation, images, and a little JavaScript.

This is a student project, not an official NASA website. The telescope content and images have their own sources and are not my original research or photography.

## Other work

The other folders contain CSS demos, positioning exercises, a cycle lab, and an early prototype. The root `index.html` links to the coursework.

## Open it locally

Clone or download the repo and open `index.html` in a browser. To go straight to the telescope project, open `Telescopes Web-Dev/index.html` instead. You can also serve the folder using an editor's local preview server.

There is no npm setup or backend. Some pages are class exercises or unfinished layouts, rather than complete services.
